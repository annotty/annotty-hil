# 2026-09-24 HIL 設定の「かんたん接続」（キー付き URL の自動入力）

## 背景
Server URL と API キーを手で入力するのは使いにくい。サーバーが画面に表示するキー付き URL
（例: `https://xxxx.trycloudflare.com/web/?key=...`）から自動で入力してほしい、というユーザーの要望。
最初は QR コードの読み取りとして実装したが、実際には「文字列が表示された画面」を読み取るとのことで、文字認識（OCR）に変更した。

## 変更
1. `Services/HIL/HILSettings.swift` `applyConnectionURL(_:)`
   - URL の query（`key` / `api_key` / `apikey`）からキーを取り出し、Server URL はオリジン（scheme://host[:port]）だけにする
     （`/web/` はサーバーのブラウザ用ページのパスで、API のベースではないため）
   - 成功したら `isEnabled = true`
2. `Views/HIL/ServerSettingsView.swift`
   - 「かんたん接続」欄を追加: 「画面のURLをカメラで読み取る」（VisionKit `DataScannerViewController`、`.text()`）と `PasteButton`
   - Server URL 欄に `key=` を含む文字列が入ると、自動で振り分ける
   - どの方法でも、振り分けたあとに自動で接続テストする
   - OCR は各行 → 全行を連結した文字列の順に、空白を除いてから `https?://...[?&]key=...` を探す（長い URL の折り返し対策）
3. `Info.plist` に `NSCameraUsageDescription` を追加
