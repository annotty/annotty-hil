# 2026-09-25 カメラでの URL 読み取りを削除

  「かんたん接続」は `PasteButton` だけにし、説明文も更新した
- `Info.plist`: `NSCameraUsageDescription` を削除（変更前の状態に戻った）
- 残した機能: `HILSettings.applyConnectionURL`（キー付き URL → Server URL + API Key）、Server URL 欄での自動振り分け、振り分け後の自動接続テスト
